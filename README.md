# Biocrust 探索者 (Biocrust Explorer)

这是一个关于生物土壤结皮（Biological Soil Crusts）的交互式科普教育游戏。游戏通过四个精心设计的关卡，向玩家科普生物结皮的基础组成、生态功能、保护恢复以及未来的星际应用潜力。

## 🎮 游戏关卡介绍
1. **第一关：藓类对对碰** - 记忆配对玩法。找出相同的蓝细菌照片以通关，了解藓类是生物结皮的优势种。
2. **第二关：长城修理工** - 拼图挑战。拖拽碎片还原带有生物结皮的长城，了解生物结皮在保护遗址方面的生态作用。
3. **第三关：生物结皮大合成** - 合成升级玩法。合并相同的结皮等级直至生成“绿色山坡”，了解人工接种与培养对结皮恢复的重要性。
4. **第四关：行星农场** - 反应挑战玩法。在太空基地中为随机生成的生物结皮浇注营养液，防止它们枯萎，畅想利用生物结皮改造外星星球生态的未来。

## 💻 本地运行指南 (Local Development)

请确保你的电脑上已安装 [Node.js](https://nodejs.org/)。

1. **克隆或下载本仓库**到你的电脑。
2. 在项目根目录打开终端 (Terminal)，运行以下命令安装所需依赖：
   ```bash
   npm install
   ```
3. 启动本地开发服务器：
   ```bash
   npm run dev
   ```
4. 在浏览器中打开终端显示的本地地址（通常是 `http://localhost:5173`）即可开始游玩。

## 📦 桌面版构建向导 (Desktop App Build)
本项目已配置了 GitHub Actions。当你将代码推送到 GitHub 时，会自动将本网页游戏打包为 Windows (`.exe`) 和 macOS (`.dmg`) 的桌面应用程序。你可以直接在 GitHub 仓库的 **Releases** 页面下载安装。
